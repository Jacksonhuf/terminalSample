# Changelog — Browser Action Adapter (Chrome Extension)

## [0.1.0] — 2026-08-12

### Added

- MV3 extension: background service worker, content script, side panel, options page
- `/v1/browser/sessions` API support (default)
- Legacy `/api/browser/runs` fallback
- Commands: goto, click, fill, select, extract, scroll, wait, snapshot, finish, noop
- Configurable Bridge URL and poll interval
